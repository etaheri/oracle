Those files win on any conflict; this is the fast path for design skills.

## Target audience
Daily-habit puzzle players — the Wordle/NYT-Games audience — who want a
one-minute ritual with a scoreboard. They are not finance/prediction-market
people; the game must read as a game, not a trading terminal. Judges of
Shipaton 2026 (Best Game, RevenueCat Design) are a second, explicit audience.

## Use cases
1. Answer five daily yes/no forecast questions before noon ET; sealing is final.
2. Read yesterday's result — the crowd, the machine's own answer, points.
3. Track a running Oracle Score, vigil (streak), and ledger over time.
4. First-run: learn the rules (the Rites) and take one practice call.
5. Subscribe to Outseen Plus (shields, extras) — the paywall.

## Brand personality / tone
**Poetic, intelligent, sacred, slightly surreal, premium.**
The tension the whole system exists to hold:
*old-world humanity × timeless sculpture × luminous intelligence × restrained
digital interference.*

Explicitly NOT: generic AI, cyberpunk, wellness-tech, stock photography,
trading-app, Matrix-green, neon-on-dark.

### Four materials — never blend them, the contrast is the point
1. **Paint** — humanity, history, emotion (Renaissance painted hands)
2. **Marble** — permanence, structure, trust (Carrara sculpture)
3. **Glass & light** — intelligence, possibility, the product (the orb)
4. **ASCII** — computation quietly entering a museum artifact ("Terminal Patina")

### Two voices
- **Machine voice** (IBM Plex Mono, tracked caps) owns all chrome, all state,
  all instruction. Terse, declarative, never chatty, never apologises.
- **Temple voice** (Marcellus display / Cinzel carved caps) is *scarce by
  design* — the wordmark, card numerals, day points, and the card/share
  artifacts only. Scarcity keeps it sacred.

### Terminal Patina — the signature
Sparse ASCII from `. : - + * # % / \ ( ) 0 1`, punctuation-first. Covers 5–20%
of a composition. Discovered as a detail; never dominant. Approved behaviours:
edge shimmer, materialization, halo atmosphere, glass reflection, digital
shadow. Character changes are **quantized to steps (2–4/sec), never randomized
per frame**. Reduced motion freezes the pattern and keeps it static.
Banned: Matrix green, code blocks, readable code, RGB split, VHS, pixel sort,
dense character rain, rapid flicker, neon.

### Palette (see `apps/mobile/src/theme.ts` — it is the implementation of §7)
Museum white ground `#F7F6F2`, ink `#17191F`, muted ink `#666A73`, aged gold
`#AA8A50` (gold text tier `#7E6538`), ultramarine `#243D78` = YES, vermilion
`#A84B35` = NO, midnight museum `#121A2B` for the night realm (share card).
ASCII colours: warm white, cool blue-gray, pale lavender, occasionally muted
ink. Never terminal green.

### UI direction
Warm-white foundation, dark ink type, very restrained borders, generous
spacing, soft corners *selectively*, minimal gradients, orb as a stateful
product object, ASCII used for delight/loading/activation/transitions.
The UI must not imitate a Renaissance interface — the historical layer lives
in imagery and motion, not in chrome.

## Constraints
- Expo SDK 57 / React Native / expo-router. Read
  https://docs.expo.dev/versions/v57.0.0/ before writing Expo code.
- Reanimated + Skia are available and already in use (orb, share card, patina).
- Type goes through the `role` scale in `src/ui/Text.tsx` — size, tracking, and
  line box live in `theme.ts`, not at the call site.
- Every chrome row has an explicit line box (`ROW_H`) so late-arriving lines
  reserve their slot and never shove the composition.
- Dynamic Type: chrome is capped (`CHROME_CAP`), reading text is not.
- Reduced Motion and Reduce Transparency both have defined fallbacks.
- 4pt spacing scale; page gutters 20pt or safe inset, whichever is greater.

## Differentiation — the one thing to remember
A museum-white page where a machine *prints* its lines out of ASCII static,
numbers its rules in carved Roman numerals, and holds a luminous glass orb
that breathes. It should look like a Renaissance artifact that a terminal has
quietly gotten into.
